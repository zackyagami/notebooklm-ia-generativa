# 🚀 Explorando o Poder do NotebookLM para Aprendizagem sobre IA Generativa

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como parte do desafio **"Treinando uma IA de Aprendizagem: Explore o Poder do NotebookLM"** da DIO.

O objetivo foi utilizar o NotebookLM como ferramenta de aprendizagem ativa para estudar o tema **Inteligência Artificial Generativa**, explorando técnicas de pesquisa, curadoria de conteúdo, organização do conhecimento e engenharia de prompts.

Durante o projeto, foram selecionadas fontes confiáveis, realizados experimentos com diferentes tipos de perguntas e produzidos materiais de apoio para revisão e aprendizado contínuo.

---

# 🎯 Objetivos de Aprendizagem

- Compreender os conceitos fundamentais de IA Generativa.
- Entender o funcionamento dos Large Language Models (LLMs).
- Identificar aplicações práticas da IA Generativa.


ou

```text

```

### Solução

Solicitar explicitamente:

```text
Inclua exemplos práticos de empresas que utilizam IA Generativa.
```

# 📖 Miniguia de Estudos sobre IA Generativa

## O que é IA Generativa?

IA Generativa é uma área da Inteligência Artificial especializada na criação de novos conteúdos a partir dos padrões aprendidos durante seu treinamento.

Esses conteúdos podem incluir:

- Textos
- Imagens
- Vídeos
- Áudios
- Códigos de programação

---

## Como Funciona?

De forma simplificada:

1. O modelo recebe grandes volumes de dados.
2. Aprende padrões existentes nesses dados.
3. Utiliza esses padrões para criar novos conteúdos.
4. Gera respostas com base nos comandos recebidos.

---

## Principais Tecnologias

### Machine Learning

Método que permite aos sistemas aprenderem a partir de dados.

### Deep Learning

Subárea do Machine Learning baseada em redes neurais profundas.

### LLMs (Large Language Models)

Modelos de linguagem treinados com grandes quantidades de texto.

Exemplos:

- GPT
- Gemini
- Claude
- Llama

# 📘 Glossário

## Inteligência Artificial (IA)

Capacidade de sistemas computacionais executarem tarefas que normalmente exigiriam inteligência humana.

---

## IA Generativa

Subárea da IA voltada para criação de conteúdos originais.

---

## Prompt

Instrução fornecida ao modelo para geração da resposta.

---

## LLM

Large Language Model, um modelo treinado com grandes volumes de textos.

---

## Machine Learning

Técnica que permite que sistemas aprendam padrões a partir dos dados.

---

## Deep Learning

Técnica avançada baseada em redes neurais artificiais.

---

## Token

Unidade básica utilizada pelos modelos para processar textos.

---

## Alucinação

Quando a IA apresenta informações incorretas como se fossem verdadeiras.

---

## Fine-Tuning

Processo de ajuste especializado de um modelo previamente treinado.
